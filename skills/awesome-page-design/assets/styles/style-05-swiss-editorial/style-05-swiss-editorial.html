Component behavior

Buttons, feedback, spacing, and responsive rules.

Mastheads, object boards, accession rows, source ledgers, issue metrics, and compact text actions define the page.

  • ButtonsUse text-link buttons, underlined actions, rule-line tabs, and almost no filled buttons unless the action is decisive.
  • FeedbackUse editorial callouts, margin notes, and rule-separated validation messages instead of colored bubbles.
  • SpacingUse column gutters of 24-32px, strict baselines, thin dividers, and wide reading measures.
  • ResponsiveDesktop uses columns; tablet narrows metadata into a top strip; mobile preserves reading order with actions under the headline.
