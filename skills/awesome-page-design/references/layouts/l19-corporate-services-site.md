# L19 - Corporate Services Site

Use this layout for agencies, consultancies, studios, solution providers, and service-led companies.

## Structure

- Service-led hero that states the problem and engagement model.
- Sticky service/category navigation for scanning, with the inquiry action visible after the service categories.
- Primary engagement panel that names the offer, timeline, workstreams, and expected artifacts.
- Artifact preview band for evidence walls, blueprints, prototypes, roadmaps, governance docs, or adoption plans.
- Process or service cards that explain how the company works and what each phase produces.
- Case proof row or industry examples that connect the service model to real buyer contexts.
- Optional contact section after the buyer understands scope and delivery model.

## Required States

- Clarify service scope before showing process detail.
- Support both high-level scanning and deeper service comparison.
- Show tangible delivery artifacts before relying on abstract capability claims.
- Make inquiry/contact action available after the user understands the offer.
- Show artifacts, outcomes, timelines, or delivery evidence so the page does not feel like generic marketing copy.

## Avoid

- Listing services as generic chips without explanation.
- Four identical cards with no hierarchy, artifacts, or buyer evidence.
- Making the process look like a generic agency timeline when the buyer needs delivery confidence.
- Overusing portfolio visuals when the buyer needs process clarity.
- Making every service card the same size if one is primary.
