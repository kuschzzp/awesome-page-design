# L16 - Personal Portfolio Home

Use this layout for designers, engineers, consultants, and personal brand websites that need a strong first impression plus selected work.

## Structure

- Minimal personal navigation.
- Large positioning statement paired with a profile/status card in the first viewport.
- Proof chips for shipped systems, years of practice, availability, or other credible signals.
- A horizontal capability marquee that makes the person's specialty concrete before the project grid.
- Selected work grid with one dominant featured project and two supporting projects.
- Project cards should include role/context, outcome metric, and a visual placeholder or project image.
- Supporting notes below for working method, client fit, writing, or contact.

## Required States

- Make the person and their value proposition visible in the first viewport.
- Make the specialty visible in plain language, not only through decorative visuals.
- Keep project cards specific: role, outcome, and context.
- Ensure the layout still works with only two or three projects.
- Preserve a personal point of view; this should not feel like a generic agency homepage.

## Avoid

- Generic resume-style grids with no point of view.
- Overly decorative cards that hide the actual work.
- Generic "creative portfolio" styling with no domain, process, or result signal.
- Treating this as a corporate landing page.
