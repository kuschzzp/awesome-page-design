# L15 - Operations Timeline Console

Use this layout for incident operations, deployment tracking, fulfillment workflows, and support escalation screens.

## Structure

- Top status header with escalation or incident actions.
- Summary KPI strip for operational load.
- Queue rail for workflow categories.
- Central event timeline with timestamps and status changes.
- Detail/runbook panel for the current event.

## Required States

- Show event severity and ownership clearly.
- Include resolved, delayed, blocked, and escalated states.
- Preserve chronological scanability on mobile.

## Avoid

- Mixing timeline events with unrelated dashboard cards.
- Hiding the current owner or next action.
- Using color as the only severity indicator.
