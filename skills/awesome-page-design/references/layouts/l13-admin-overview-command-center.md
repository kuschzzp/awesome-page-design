# L13 - Admin Overview Command Center

Use this layout for admin homepages, SaaS control centers, and leadership-facing operational summaries.

## Structure

- Persistent left navigation for major operational areas.
- High-priority status hero that summarizes the day.
- KPI grid for the few metrics that drive action.
- Secondary panels for workload maps, alerts, notes, or team health.

## Required States

- Highlight urgent items without turning the whole page into an alert screen.
- Include empty and loading states for metrics and workload panels.
- Provide clear drill-down paths from every status card.

## Avoid

- Turning the overview into a dense table page.
- Showing every metric at the same priority.
- Using decorative charts that do not lead to an action.
