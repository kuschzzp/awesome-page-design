# L09 - Portfolio Case Study

## Purpose

Use this framework for portfolios, studio case studies, product launch stories, and project retrospectives.

## Structure

- Project hero with name, role, timeframe, and outcome.
- Problem/context section.
- Process or exploration section.
- Visual evidence: screens, artifacts, diagrams, or prototypes.
- Results and metrics.
- Reflection or lessons.
- Next project navigation.

## Required States

- Image loading state.
- Media caption and attribution.
- External link states.
- Mobile image scaling.

## Responsive Behavior

- Keep narrative sequence linear.
- Avoid side-by-side layouts that make images too small.
- Use sticky metadata only when it does not block content.

## Works Well With Visual Styles

I Swiss Editorial, M Resonant Stark, V Spectrum Creative, O Human Scribble, F Neo-Brutalism.

## Avoid

- Generic marketing copy without project evidence.
- Hiding outcomes.
- Overusing cards inside a story.
