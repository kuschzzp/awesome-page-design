# Bento Grid 设计系统文档

> 基于 `version-d-bento.html` 的完整设计系统分析
> 风格名称：Bento Grid（Apple 风格便当盒布局）

---

## 重要使用原则

本文件提供的是视觉风格提示，不是固定页面布局方案。示例 HTML 的页面结构仅用于统一展示和截图，不应在真实项目中照搬。后续开发时，应根据用户需求、业务流程、内容优先级和设备场景重新设计页面布局；可复用的是配色、字体、圆角、边框、阴影、质感、状态和动效等视觉语言。

---

## 1. 风格定义与核心精神

**核心精神**：极简、克制、信息密度与秩序感的完美平衡。借鉴 Apple 官网的设计语言，以 Bento Grid（便当盒式网格布局）为核心组织形式，将不同类型、不同权重的内容模块按比例放入精心规划的网格单元格中，形成一种"有序中的灵活"——既保持整体结构的严谨一致性，又允许各模块在尺寸与内容上自由变化。

**风格关键词**：极简主义、Bento 布局、Apple 式克制、信息密度、白色基调、弹性缩放

**设计哲学**：
- **内容即结构**：网格尺寸直接反映内容权重（大新闻占 2×2，统计数据占 1×1）
- **克制装饰**：几乎零装饰元素，所有视觉层次通过尺寸、字重、色彩微妙差异实现
- **呼吸感**：在信息密集的网格中，通过充足的圆角、内边距和极淡边框维持视觉舒适度
- **功能驱动**：每个交互细节都有明确目的，hover 缩放只为提示可点击性，无纯装饰性动效

## 2. 色彩体系

### 2.1 主调色板

| 角色 | CSS 变量 | 色值 | 用途 |
|------|---------|------|------|
| 页面背景 | `--bg` | `#f5f5f7` | 全局浅灰背景，Apple 标准背景色 |
| 卡片背景 | `--card` | `#ffffff` | 所有白色卡片模块 |
| 深色卡片 | `--card-dark` | `#1d1d1f` | 本周概览深色区域 |
| 主文本 | `--text` | `#1d1d1f` | 标题、重要信息 |
| 次文本 | `--text2` | `#6e6e73` | 描述文字、摘要 |
| 辅助文本 | `--text3` | `#86868b` | 元信息、时间、来源 |
| 边框 | `--border` | `rgba(0,0,0,0.04)` | 极淡分隔线 |

### 2.2 功能色（Accent Colors）

| 角色 | CSS 变量 | 主色 | 背景（8%透明度） | 用途 |
|------|---------|------|------------------|------|
| 主强调 | `--blue` | `#0071e3` | `rgba(0,113,227,0.08)` | 品牌、排名徽章、Pill激活态 |
| 增长/成功 | `--green` | `#34c759` | `rgba(52,199,89,0.08)` | 正向变化、新鲜标签 |
| 紧急/热门 | `--red` | `#ff3b30` | `rgba(255,59,48,0.08)` | 突发标签、负向变化 |
| 警告/政策 | `--orange` | `#ff9500` | `rgba(255,149,0,0.08)` | 政策标签 |
| 特殊/应用 | `--purple` | `#af52de` | `rgba(175,82,222,0.08)` | 应用标签、统计值 |

### 2.3 色彩推导公式

- **背景色推导**：所有功能色背景 = `rgba(R, G, B, 0.08)`，即功能色的 8% 透明度版本
- **深色区域文字推导**：白色文字层级 → `rgba(255,255,255,0.5)` 作为辅助文字
- **深色区域边框推导**：`rgba(255,255,255,0.08)`
- **选区色**：`::selection` 使用 `--blue` 配白色文字

### 2.4 色彩使用规则

1. 功能色仅用于语义标记（标签、统计值、变化方向），绝不用于大面积装饰
2. 功能色背景（8%版本）用于标签背景和徽章底色，形成"色点+浅底"的克制标记
3. 主文本色 `#1d1d1f` 与背景 `#f5f5f7` 对比度约为 15:1，满足 WCAG AAA
4. 次文本 `#6e6e73` 对比度约 4.6:1，满足 WCAG AA
5. 辅助文本 `#86868b` 对比度约 3.1:1，仅用于非关键信息

## 3. 排版体系

### 3.1 字体

- **主字体**：`Inter`（Google Fonts 引入）
- **回退字体栈**：`-apple-system, BlinkMacSystemFont, sans-serif`
- **字重范围**：300 / 400 / 500 / 600 / 700 / 800

### 3.2 字号层级

| 层级 | 用途 | 字号 | 字重 | letter-spacing | line-height |
|------|------|------|------|----------------|-------------|
| Hero 标题 | 头条新闻标题 | `24px` | 700 | `-0.03em` | `1.25` |
| 统计数值 | 数据大数字 | `28px` | 800 | `-0.04em` | — |
| 区块标题 | 热门趋势/最新资讯标题 | `17px` | 700 | `-0.02em` | — |
| 副标题 | Hero 描述 | `14px` | 400 | 0 | `1.6` |
| 侧栏标题 | 侧栏新闻标题 | `14px` | 600 | `-0.01em` | `1.35` |
| 常规文本 | 列表条目标题 | `13px` | 500 | 0 | — |
| 小标签 | tag/pill/card-tag | `11px` | 500-600 | 0 | — |
| 微文本 | meta信息/footer | `10px-11px` | 400-500 | 0 | — |
| 导航链接 | 导航栏链接 | `12px` | 500 | 0 | — |
| 品牌名 | 导航栏品牌 | `15px` | 700 | `-0.02em` | — |
| 日期 | 导航栏日期 | `11px` | 400 | 0 | — |

### 3.3 排版特征

- **紧凑 letter-spacing**：标题级普遍使用 `-0.02em` 到 `-0.04em`，营造 Apple 式紧凑感
- **负值字间距层级**：字号越大 → letter-spacing 越负（28px → -0.04em, 24px → -0.03em, 17px → -0.02em）
- **行高策略**：标题 1.2-1.35（紧凑），正文 1.5-1.6（舒适）
- **字重对比**：数值使用 800 极粗，正文使用 400 常规，形成强烈的视觉节奏

## 4. 边框/圆角/阴影体系

### 4.1 圆角

| CSS 变量 | 值 | 用途 |
|---------|------|------|
| `--radius` | `20px` | 所有主要卡片（bento-hero, bento-stat, bento-list, bento-cards 等） |
| `--radius-sm` | `12px` | 列表条目、卡片内部小卡片、统计区域 |
| 固定值 | `7px` | Logo 圆角 |
| 固定值 | `6px` | 标签圆角、排名徽章 |
| 固定值 | `4px` | 最小标签圆角（card-tag） |
| 固定值 | `20px` | Pill 药丸按钮 |
| 固定值 | `8px` | wk-icon 图标容器 |
| 固定值 | `50%` | tag-dot 圆点 |

### 4.2 边框

| 位置 | 值 | 用途 |
|------|------|------|
| 全局边框 | `1px solid rgba(0,0,0,0.04)` | 顶栏底边、页面底边 |
| 深色区域 | `1px solid rgba(255,255,255,0.08)` | 本周概览条目分隔 |
| 其他 | 无边框 | 所有卡片均无显式边框，仅靠背景色区分 |

### 4.3 阴影

- 本设计系统**不使用显式 box-shadow**
- 卡片通过白色背景与 `#f5f5f7` 页面背景的微妙色差形成视觉分层
- 顶栏使用 `backdrop-filter: blur(40px) saturate(2)` 实现毛玻璃模糊而非阴影

## 5. 装饰元素/交互细节

### 5.1 装饰元素

| 元素 | 位置 | 形态 | 作用 |
|------|------|------|------|
| 红色脉冲圆点 | Hero tag 内 | 5px 圆形, `--red` 色, blink 动画 | 标记突发/紧急状态 |
| 蓝色光晕 | Hero 右上角 | 200px 圆形径向渐变, `--blue-bg` → transparent 70% | 极淡的品牌色氛围装饰 |
| 排名徽章 | 热门列表 | 24px 方形, `--blue-bg` 底 + `--blue` 字 | 编号标记 |
| wk-icon | 本周概览 | 32px 方形, emoji + 彩色半透明底 | 趋势条目视觉标识 |
| Pill 药丸按钮 | 热门趋势筛选 | 灰底 → 蓝底白色激活态 | 时间维度筛选 |
| Logo | 顶栏 | 28px 圆角方形, 蓝底白字 "AI" | 品牌标识 |

### 5.2 交互细节

| 交互 | 元素 | 效果 | 参数 |
|------|------|------|------|
| Hover 缩放 | bento-hero | `transform: scale(1.01)` | `0.25s` transition |
| Hover 缩放 | bento-stat | `transform: scale(1.02)` | `0.25s` transition |
| Hover 缩放 | bento-side | `transform: scale(1.01)` | `0.25s` transition |
| Hover 缩放 | card (卡片内) | `transform: scale(1.02)` + 背景变深 | `0.2s` + `0.15s` |
| Hover 背景 | list-item | `background: var(--bg)` | `0.15s` transition |
| Hover 颜色 | nav 链接 | `color: var(--text)` | `0.15s` transition |
| Hover 颜色 | footer 链接 | `color: var(--text)` | — |
| 脉冲动画 | tag-dot | opacity 1→0.3→1 | `1.5s infinite` |
| 点击切换 | pill 按钮 | active class 切换 | JS 控制 |

### 5.3 毛玻璃顶栏

- 背景：`rgba(245,245,247,0.72)`（72% 透明度页面背景色）
- 模糊：`backdrop-filter: blur(40px) saturate(2)`
- 效果：内容滚动时顶栏与页面内容产生微妙的融合感

## 7. 响应式策略

### 7.1 断点定义

| 断点 | 值 | 网格变化 |
|------|------|----------|
| 桌面 | > 768px | 4列网格 |
| 平板 | ≤ 768px | 2列网格 |
| 手机 | ≤ 480px | 1列网格 |

### 7.2 各断点调整

**平板（≤768px）**：
- 网格从 4 列变为 2 列
- Hero 占满 2 列（grid-column: 1/3）
- 侧栏新闻占满 2 列
- 列表/卡片占满 2 列
- 卡片网格变为 1 列（cards-grid: 1fr）

**手机（≤480px）**：
- 网格变为 1 列
- 所有模块占满 1 列
- 导航链接隐藏（`.topbar-nav { display: none }`）

### 7.3 响应式设计理念

- Bento Grid 的核心优势：通过 `grid-column` 范围的灵活调整，无需改变组件本身即可适配不同屏幕
- 大屏信息密度高（4列共存），小屏按比例合并，保持视觉节奏不变

## 10. 适用/不适用场景

### 10.1 适用场景

- **新闻/资讯聚合平台**：Bento 布局天然适合混合内容类型的聚合展示
- **数据仪表盘**：统计卡片 + 列表 + 趋势图的组合与 Dashboard 需求完美契合
- **科技产品展示页**：Apple 式极简语言天然适配科技/AI主题
- **内容发现页面**：用户需要快速浏览不同类型内容时，Bento 提供最优信息扫描路径
- **SaaS 产品首页**：功能模块化展示、数据亮点突出

### 10.2 不适用场景

- **长文阅读/博客**：Bento 布局打断阅读连贯性，不适合沉浸式阅读
- **社交媒体 Feed**：需要线性流式浏览，Bento 的跳跃式布局会造成认知负担
- **情感化/品牌叙事页面**：极简克制语言无法承载强烈的情感表达
- **儿童/游戏类产品**：过于严肃和克制，缺乏趣味性
- **极低信息密度场景**：Bento 的网格结构在内容稀疏时会产生大量空白浪费

## 12. 变体建议

### 12.1 色彩变体

- **暗色版 Bento**：背景改为 `#1d1d1f`，卡片改为 `rgba(255,255,255,0.08)`，功能色背景改为 15% 透明度，形成 Apple 暗色模式的 Bento 布局
- **品牌色版**：将 `--blue` 替换为品牌主色，所有功能色背景和徽章随之变化
- **单色版**：去除所有功能色，仅用灰度层级区分信息类型，极致极简

### 12.2 网格变体

- **5列 Bento**：更大屏幕（>1400px）下扩展为 5 列，允许更精细的内容比例分配
- **不对称 Bento**：使用非等宽列（如 2fr + 1fr + 1fr），让主内容区获得更多空间
- **3列紧凑版**：中等屏幕的 3 列变体，Hero 占 2 列，统计数据横排

### 12.3 内容变体

- **数据仪表盘版**：增加图表模块（用 CSS/SVG 实现 mini sparkline），统计卡片增加迷你趋势线
- **图片增强版**：Hero 卡片加入背景图 + 文字叠加，增加视觉冲击力
- **时间线版**：将本周概览模块改为时间线可视化形式

## 13. 动效/微交互

### 13.1 动效清单

| 动效名 | 触发 | 属性变化 | 时长 | 缓动 | 作用 |
|--------|------|----------|------|------|------|
| Hero hover | 鼠标悬停 | scale(1→1.01) | 0.25s | ease | 可点击性提示 |
| Stat hover | 鼠标悬停 | scale(1→1.02) | 0.25s | ease | 数据卡片强调 |
| Side hover | 鼠标悬停 | scale(1→1.01) | 0.25s | ease | 可点击性提示 |
| Card hover | 鼠标悬停 | scale(1→1.02) + bg变深 | 0.2s/0.15s | ease | 小卡片强调 |
| List hover | 鼠标悬停 | background → var(--bg) | 0.15s | ease | 行高亮 |
| Nav hover | 鼠标悬停 | color → var(--text) | 0.15s | ease | 导航反馈 |
| Blink | 自动循环 | opacity 1→0.3→1 | 1.5s | ease | 突发状态脉冲 |
| Scroll | 滚动页面 | smooth scroll | — | smooth | 滚动体验 |

### 13.2 动效设计理念

- **克制原则**：所有 hover 效果仅做极微小的缩放（1-2%），避免夸张变形
- **功能性**：每个动效都有明确交互目的，不存在纯装饰性动画（除 blink 脉冲用于紧急标记）
- **统一缓动**：全部使用默认 ease 缓动，保持一致的加速/减速节奏
- **无入场动画**：页面加载时无淡入、滑入等入场效果，直接呈现内容

## 14. 实施指南/注意事项

### 14.1 实施要点

1. **网格布局优先**：所有内容模块必须先确定其在 Bento Grid 中的位置（grid-column / grid-row），再处理内部样式
2. **CSS 变量必须**：所有颜色、圆角通过 CSS 变量定义，便于后续主题切换
3. **backdrop-filter 兼容性**：毛玻璃效果需要 `backdrop-filter` 支持，Safari 需 `-webkit-` 前缀；旧浏览器应提供 fallback 背景
4. **Inter 字体加载**：通过 Google Fonts @import 引入，需考虑加载延迟对排版的影响；建议设置 `font-display: swap`
5. **gap 间距统一**：Bento Grid 的 `gap: 16px` 是核心间距，所有模块间依赖此值保持一致性

### 14.2 性能注意事项

- `backdrop-filter: blur(40px) saturate(2)` 在大区域上可能造成性能问题，仅在顶栏（48px高）使用可控
- hover `transform: scale()` 应确保元素有 `will-change: transform` 或浏览器自动优化
- 避免在大量卡片上同时使用 `backdrop-filter`

### 14.3 可访问性

- 文本颜色对比度满足 WCAG AA（主文本 15:1 AAA, 次文本 4.6:1 AA）
- 辅助文本 `#86868b` 对比度 3.1:1，仅用于非关键信息，关键信息应使用 `--text2`
- `::selection` 使用蓝底白字，对比度充足
- 所有交互元素有 cursor: pointer 和视觉反馈

### 14.4 扩展建议

- 增加暗色模式变量组：`[data-theme="dark"]` 下翻转 `--bg` 和 `--card-dark`
- 增加品牌色覆盖：通过修改 `--blue` 实现快速品牌适配
- 响应式可增加 1400px 断点扩展为 5 列
- 考虑增加 `prefers-reduced-motion` 媒体查询，在减少动画偏好下禁用 blink 和 scale 动效
