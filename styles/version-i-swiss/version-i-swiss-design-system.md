## 重要使用原则

本文件提供的是视觉风格提示，不是固定页面布局方案。示例 HTML 的页面结构仅用于统一展示和截图，不应在真实项目中照搬。后续开发时，应根据用户需求、业务流程、内容优先级和设备场景重新设计页面布局；可复用的是配色、字体、圆角、边框、阴影、质感、状态和动效等视觉语言。

## 一、风格定义

**Swiss Editorial（瑞士国际主义排版）** 是源自 1950-60年代瑞士设计学院（Josef Müller-Brockmann / Max Bill / Armin Hofmann）的平面设计哲学，在当代以 The New York Times / Bloomberg / The Economist / Monocle 等出版物为数字化延续。核心理念：

- **网格至上**：一切遵循严格的网格系统，不靠圆角/阴影/渐变制造层次，靠**线条分割**和**对齐**
- **零圆角**：所有元素圆角为 0，绝无 4px/8px/12px/16px 圆角。矩形是唯一的形状
- **线条即层次**：1px 线做分隔，2px 线做区块标题底线，4px 线做重大分割（divider），不靠阴影
- **红色唯一强调**：全站只有一个功能性强调色（`#e63946`），不允许多色强调
- **大写字母标签**：所有标签、导航、区块标题一律 `text-transform: uppercase` + 大字间距（`0.08-0.15em`）
- **字重极端对比**：标题 900（黑体）+ 正文 400（常规）+ 小标签 800（超粗），从极粗到极细的跳跃
- **monospace 数据**：时间、计数、来源等"数据类"文字用 monospace 字体，与正文 Inter 形成"内容+数据"双节奏
- **无卡片框架**：新闻不用独立"卡片容器"，用**列分割线**（`border-right: 1px solid`）隔开三列

## 二、色彩体系

### 2.1 调色板

| 角色 | CSS 变量 | 值 | 用途 |
|---|---|---|---|
| 页面背景 | `--bg` | `#fafafa` | 近白但非纯白，极微灰调 |
| 卡片/导航背景 | `--card` | `#ffffff` | 纯白 |
| 主文字 | `--text` | `#111111` | 近纯黑但非纯黑 |
| 辅助文字 | `--text2` | `#555555` | 中灰（无色相偏移，纯灰） |
| 弱化文字 | `--text3` | `#999999` | 浅灰 |
| 唯一强调色 | `--accent` | `#e63946` | 红色，用于：品牌名、导航激活、突发标签、热门分类、区块标记、排名数字、订阅区背景 |
| 分割线 | `--rule` | `#111111` | 与主文字同色，所有分隔线 |

### 2.2 色彩使用规则

1. **无色相灰度层级**：文字用 `#111111` → `#555555` → `#999999` 三级灰度，这些是**纯灰**，没有蓝偏移、暖偏移或紫偏移。与版本A的冷灰、Brutalism的暖灰截然不同
2. **分割线与文字同色**：所有 `border` 用 `#111111`（近纯黑），与主文字一致，像报纸的铅字分割线
3. **红色是唯一功能性色**：全站只有 `#e63946` 一个强调色，不允许第二个强调色。热门标签是红色，新鲜标签是绿色——但绿色不是系统强调色，它只是分类标识色
4. **分类标识色不污染系统**：hot=accent红, new=green, policy=orange, app=blue 这些颜色只出现在 `.card-cat` 和 `.side-cat` 的文字色中，绝不用于边框、背景、按钮或其他结构性元素
5. **无背景填充标签**：标签只有文字色（`color`），无背景填充、无边框。像报纸的分类标注——只改颜色不改形状

### 2.3 调色板推导公式

Swiss 设计的核心是**灰度 + 单强调色**：

| 角色 | 推导规则 |
|---|---|
| 文字灰度 | 纯灰三级：×900黑 → ×500中灰 → ×300浅灰（无色相偏移） |
| 强调色 | 任何高饱和单色，只选一个。经典：红 `#e63946`，也可选蓝 `#0057ff`、橙 `#ff6b00` |
| 分割线 | 与主文字同色（近纯黑） |
| 背景 | `#fafafa`（近白）或 `#ffffff`（纯白），绝不选有色相的底色 |

## 三、排版体系

### 3.1 字体

| 属性 | 值 | 说明 |
|---|---|---|
| 主字体 | `Inter` | 现代无衬线，极宽字重档位（300-900），Swiss 需要字重极端对比 |
| 回退 | `Helvetica, Arial, sans-serif` | Helvetica 是 Swiss 设计的 DNA，Inter 是数字时代的 Helvetica |
| 数据字体 | `monospace` | 系统等宽，用于时间、计数、Footer、元信息 |
| 字重档位 | 300-900 全档 | 900（标题）+ 800（标签）+ 700（副标题）+ 600（小标签）+ 500（导航）+ 400（正文） |

**字体选择原则**：Inter / Helvetica Neue / GT Americana / ABC Diatype / Akzidenz-Grotesk 都适合。关键是"无衬线 + 极宽字重档位"。避免衬线字体（Swiss 国际主义拒绝衬线），避免 Display 字体（太装饰性）。

### 3.2 字重极端对比——Swiss 的核心特征

Swiss 设计最显著的排版特征是**字重的极端跳跃**：

| 层级 | 字重 | 用途 |
|---|---|---|
| 900 | Hero 标题、排名数字 | 极粗黑体，视觉最强 |
| 800 | 导航品牌、区块标题、标签文字 | 紧凑黑体，"标签感" |
| 700 | 侧栏标题、新闻卡片标题、热门条目标题 | 半粗体 |
| 600 | 导航链接、筛选链接、热门条目、Footer | 中偏粗 |
| 500 | 导航日期 | 中等 |
| 400 | 正文描述、新闻摘要 | 常规，最弱 |

这种 900→400 的字重跳跃（从黑体到常规）是 Swiss 设计的 DNA——对比越强，层次越清晰。

### 3.3 大写标签体系

Swiss 的第二个标志性特征是**大量使用全大写 + 大字间距**：

| 元素 | 字号 | 字重 | 字间距 | 大写 | 字体 |
|---|---|---|---|---|---|
| 导航品牌 | `13px` | 800 | `0.15em` | uppercase | 主字体 |
| 导航链接 | `11px` | 600 | `0.08em` | uppercase | 主字体 |
| 区块标题 | `11px` | 800 | `0.15em` | uppercase | 主字体 |
| 分类标签 | `9px` | 700 | `0.12em` | uppercase | 主字体 |
| 突发标签 | `9px` | 700 | `0.1em` | uppercase | 主字体 |
| 筛选链接 | `10px` | 600 | `0.08em` | uppercase | 主字体 |
| 订阅标题 | `11px` | 800 | `0.15em` | uppercase | 主字体 |
| 订阅按钮 | `11px` | 700 | `0.08em` | uppercase | 主字体 |
| Footer | `10px` | 600 | `0.08em` | uppercase | 主字体 |

**参数规则**：
- 标签字号极小：9-13px（比正文 13-16px 更小），这是"标注"而非"标题"
- 字间距分级：导航品牌/区块标题 `0.15em`（最宽），导航链接/筛选 `0.08em`，分类标签 `0.12em`
- 全大写：所有上述元素一律 `text-transform: uppercase`
- 这套"小字+大写+大字间距"的组合像报纸的版面标注——"EDITORIAL / NEWS / OPINION"

### 3.4 正文字号层级

| 元素 | 字号 | 字重 | 字间距 | 行高 | 字体 |
|---|---|---|---|---|---|
| Hero 标题 | `42px` | 900 | `-0.04em` | `1.05` | 主字体 |
| 侧栏标题 | `15px` | 700 | `-0.02em` | `1.35` | 主字体 |
| 新闻卡片标题 | `16px` | 700 | `-0.02em` | `1.3` | 主字体 |
| Hero 描述 | `16px` | 400 | — | `1.6` | 主字体 |
| 热门条目 | `13px` | 600 | `-0.01em` | — | 主字体 |
| 新闻摘要 | `13px` | 400 | — | `1.5` | 主字体 |
| byline | `11px` | 600 | `0.05em` | — | 主字体 |
| 元信息 | `10px` | 500 | — | — | monospace |
| 卡片 footer | `10px` | 400 | `0.02em` | — | monospace |

**Hero 标题 42px / 900 / -0.04em / 1.05**——这是 Swiss 的视觉锚点：超大、极粗、极紧字间距、极窄行高。42px 标题像报纸头条。

## 四、分割线体系（替代阴影）

Swiss Editorial 不用 `box-shadow`，用**分割线（Rule）**制造视觉层次。这是最核心的区别。

### 4.1 分割线宽度分级

| 级别 | 宽度 | 用途 | 说明 |
|---|---|---|---|
| 微线 | `1px` | 导航底、侧栏分隔、热门条目分隔、列分割 | 基础分割，像报纸的细分割线 |
| 中线 | `2px` | 区块标题底线 | 区块标题的"底线强调" |
| 重线 | `4px` | Hero 后的 divider、Footer 顶 | 重大内容分割，像报纸的版面分割 |

**递进规则**：视觉重要性越高 → 线越粗。1px（微分隔）→ 2px（区块标题）→ 4px（版面分割）。

### 4.2 分割线使用场景

| 位置 | 宽度 | 颜色 | 说明 |
|---|---|---|---|
| 导航底部 | `1px` | `--rule` | 页面与导航的分界 |
| Hero 后 divider | `4px` | `--rule` | 头条区与内容区的重大分割 |
| 侧栏卡片之间 | `1px` | `--rule` | 三条副新闻的分隔 |
| byline 顶部 | `1px` | `--rule` | 标题与署名的分隔 |
| 区块标题底部 | `2px` | `--rule` | "最新资讯"标题的底线 |
| 新闻三列之间 | `1px` | `--rule` | 列分割线（`border-right`） |
| 热门条目之间 | `1px` | `rgba(0,0,0,0.08)` | 更浅的分隔（8% 黑而非纯黑） |
| Footer 顶部 | `4px` | `--rule` | 页面底部的重大分割 |

**注意**：热门条目之间用 8% 黑而非纯黑，这是 Swiss 的"密度调节"——热门列表条目更密集，用更浅的线降低视觉噪音。

### 4.3 列分割线——Swiss 的标志性布局

```css
.news-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 0;  /* 关键：gap=0 */
}
.news-card {
  padding: 20px 16px;
  border-right: 1px solid var(--rule);  /* 列分隔线 */
}
.news-card:last-child { border-right: none; }
```

**核心原则**：Swiss 的新闻网格 `gap: 0`（零间距），用列分割线代替卡片间距。这是报纸版面的布局方式——三列并排，竖线分隔，不是独立卡片。

## 五、悬停交互

Swiss Editorial 的悬停极克制——不像 Brutalism 的硬阴影、Y2K 的霓虹发光、Terminal 的边框亮起。

### 5.1 悬停效果

| 元素 | 悬停效果 | 参数 |
|---|---|---|
| 侧栏卡片 | 左缩进 + 浅红底 | `padding-left: 8px; background: rgba(230,57,70,0.04)` |
| 新闻卡片 | 浅红底 | `background: rgba(230,57,70,0.04)` |
| 热门条目 | 左缩进 + 浅红底 | `padding-left: 8px; background: rgba(230,57,70,0.04)` |
| 筛选链接 | 文字色变深 | `color: var(--text)` |
| 导航链接 | 文字色变深 | `color: var(--text)` |
| Footer链接 | 文字色变红 | `color: var(--accent)` |

### 5.2 悬停设计理念

1. **浅红底而非阴影**：4% 透明度的红色背景，像报纸上用荧光笔划过的痕迹
2. **左缩进而非上浮**：`padding-left: 8px` 而非 `translateY(-2px)`——Swiss 是"水平运动"而非"垂直运动"
3. **无 box-shadow**：Swiss 永远不用阴影。悬停只改背景色和位置
4. **极微透明度**：4% 红色背景几乎看不见，只在仔细观察时感知。这是"克制交互"——Swiss 的交互不应该喧哗

## 六、Hero 区域的特殊设计

Swiss 的 Hero 区域与所有其他风格的根本区别：**侧栏用分割线而非卡片容器**。

### 6.1 Hero 布局

| 属性 | 值 |
|---|---|
| 比例 | `2fr 1fr`（比其他风格的 1.3fr:1fr 更偏左——头条区占 2/3） |
| 间距 | `32px` |

### 6.2 Hero 主区

- **无背景容器**：Hero 主区没有 `background`、没有 `border`、没有 `box-shadow`。标题直接"浮"在页面上
- **byline 上方有分割线**：`border-top: 1px solid var(--rule)` 分隔标题与署名信息
- **标签红底白字**：`.tag` 用 `--accent` 红色填充 + 白字 + 9px + `letter-spacing: 0.1em` + uppercase

### 6.3 Hero 侧栏

- **无卡片容器**：侧栏三条新闻之间只有 `border-bottom: 1px solid var(--rule)`，没有独立卡片
- **悬停左缩进+浅红底**：`padding-left: 8px; background: rgba(230,57,70,0.04)`
- **分割线而非边框**：每条侧栏新闻之间用 1px 线分隔，像报纸版面的副新闻区

## 八、间距体系

### 8.1 外边距节奏

| 值 | 用途 |
|---|---|
| `48px` | 主区域内边距、区块间距、导航内边距、Footer内边距 |
| `32px` | Hero 列间距、导航链接间距 |
| `24px` | 区块标题底线与内容间距 |
| `20px` | 新闻卡片内边距上下 |
| `16px` | Hero 列间距（导航与内容）、侧栏卡内边距上下、byline gap |
| `12px` | 热门条目内部 gap、byline padding-top |
| `16px` | 新闻卡片内边距左右 |
| `8px` | 悬停左缩进量、订阅表单间距 |

### 8.2 内边距

Swiss 的内边距比其他风格**更不均匀**——水平内边距小于垂直内边距，像报纸版面的紧凑横向布局：

| 级别 | 值 | 用途 |
|---|---|---|
| 大 | `48px 32px` | 主区域 |
| 中 | `24px 32px` | 订阅区 |
| 卡片行 | `20px 16px` | 新闻卡片 |

## 九、响应式断点

| 断点 | 变化 |
|---|---|
| `≤ 1024px` | Hero 双列→单列；网格 3→2 列 |
| `≤ 768px` | 导航内边距 48→16；链接间距 32→16；主区域 48→32；Hero标题 42→32；网格 2→1；列分割线→行分割线（border-right→border-bottom）；热门列表双列→单列；订阅竖排；Footer竖排 |

**关键响应式转换**：新闻卡片从 `border-right`（列分割）→ `border-bottom`（行分割），从横向版面→纵向版面，像报纸从横版→纵版的版面调整。

## 十一、设计公式速查表

### Swiss 分割线层级

```css
/* 微线 - 基础分隔 */
.swiss-rule-thin {
  border-bottom: 1px solid #111111;
  /* 或 border-right: 1px solid #111111; 用于列分隔 */
}

/* 中线 - 区块标题底线 */
.swiss-rule-medium {
  border-bottom: 2px solid #111111;
}

/* 重线 - 版面分割 */
.swiss-divider {
  height: 4px;
  background: #111111;
}
```

### Swiss 大写标签

```css
.swiss-label {
  font-size: 9-11px;
  font-weight: 700-800;
  letter-spacing: 0.08-0.15em;
  text-transform: uppercase;
  color: #e63946; /* 或其他标识色 */
  /* 无背景填充，无边框，无圆角 */
}
```

### Swiss 悬停

```css
.swiss-hoverable {
  transition: background 0.15s, padding-left 0.15s;
}
.swiss-hoverable:hover {
  background: rgba(230,57,70,0.04);
  padding-left: 8px;
}
```

### Swiss 新闻网格


## 十二、适用场景与不适用场景

### 适合

- 新闻媒体 / 杂志 / 出版物官网（Swiss 的本源领域）
- 企业年报 / 投资者关系页面（严肃、克制、专业）
- 法律 / 金融 / 咨询公司官网（Swiss 的克制感传递权威）
- 学术 / 研究机构网站（Swiss 的理性气质契合学术）
- 需要大量文字内容的信息密集型页面（分割线布局比卡片布局更适合长文）
- 需要"权威感"而非"亲和感"的品牌站

### 不适合

- 消费品牌 / 生活方式类网站（Swiss 太冷，缺乏温度）
- 儿童 / 娱乐 / 游戏类网站（零圆角+纯灰+单红 = 过于严肃）
- 需要强视觉冲击力的营销页（Swiss 的克制反而削弱冲击）
- 需要复杂交互的仪表盘（分割线布局不适合嵌套面板）
- 移动端优先的产品（42px 标题在小屏幕上过大，需要 32px 断点回退）

## 十四、变体建议

| 变体 | 改什么 | 效果 |
|---|---|---|
| 蓝色 Swiss | 强调色换 `#0057ff`（深蓝），其余不变 | 像 Bloomberg / Financial Times 的蓝调 |
| Orange Swiss | 强调色换 `#ff6b00`（橙色），底色换 `#fff8f0`（微暖白） | 像 Monocle 的暖调出版物 |
| 深色 Swiss | 底色换 `#1a1a1a`，文字换 `#f0f0f0`，分割线换 `rgba(255,255,255,0.12)`，强调色保留红 | 暗色版 Swiss，像 The Verge 暗色模式 |
| Swiss × Brutalism 混合 | 保留 Swiss 的分割线+字重体系+uppercase标签，加 Brutalism 的硬阴影+粗边框 | "报纸 × 剪纸"混合体 |
| Swiss × Terminal 混合 | 保留 Swiss 的分割线+网格布局，换 JetBrains Mono 字体，换纯黑底+绿字 | "报纸 × 终端"混合体，像黑客新闻 |
| 轻量版 | 分割线全部从 `1px solid #111` 换成 `1px solid rgba(0,0,0,0.08)`，标签字号从 9-11px 放大到 11-13px | 降低视觉强度，适合信息密集页面 |
